# 🍽️ The Oracle's Plate – Multi-Role Food Delivery App

A modern food delivery Android application built using **Kotlin** and **Jetpack Compose**, implementing clean architecture principles and real-time backend integration.

This project demonstrates scalable app architecture, role-based access control, and real-world backend integration.

---

## 🚀 Features

### 👤 Multi-Role Authentication
- Buyer Login
- Seller Login / Signup
- Delivery Partner Login
- Admin Login
- Google Sign-In Support
- Firebase Authentication integration

---

### 🛒 Buyer Features
- Browse food items
- Search menu
- Add to cart
- Place orders
- View order history
- Profile management

---

### 🏪 Seller Dashboard
- Add / Edit / Delete menu items
- Upload images via Cloudinary
- Manage orders
- View listed items

---

### 🛵 Delivery Dashboard
- View assigned orders
- Order status management (Ready / Out for Delivery / Delivered)
- Map integration for tracking

---

### 🛠 Admin Dashboard
- Approve pending sellers
- View all users
- Manage all menu items
- Track all orders
- Analytics dashboard (Users, Orders, Revenue)

---

## 🏗️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **MVVM Architecture**
- **Hilt (Dependency Injection)**
- **Firebase Authentication**
- **Firebase Firestore**
- **Firebase Realtime Database**
- **REST API Integration**
- **Cloudinary (Image Hosting)**
- **DataStore**
- **Google Maps Integration**

---

## 🧠 Architecture

- Clean MVVM structure
- Role-based navigation
- State management using Compose
- Repository pattern
- Dependency injection via Hilt
- Real-time Firebase synchronization
